# OTO — 音響ファイル転送（試作版）

## 概要
GitHub Pagesで公開できる静的Webサイトです。送信側のブラウザーがファイルを4-FSK音響信号に変換して再生し、受信側のブラウザーがマイクで録音して復号します。ファイル本体をサーバーへアップロードする処理はありません。

## 公開方法
1. GitHubで新しいリポジトリを作成します。
2. `index.html` をリポジトリのルートにアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチ・`/(root)` を指定して保存します。
5. 公開されたHTTPSのURLを両端末で開きます。

## 使用方法
1. 受信側端末で「録音を開始」を押し、マイクを許可します。
2. 送信側端末でファイルを選び、「音を生成して送信」を押します。
3. 送信側の再生が終わったら、受信側で「録音を停止して復号」を押します。
4. CRC-32検証に成功した場合、表示されたリンクからファイルを保存します。

## 重要な制約
- これは音響通信の概念実証用の試作版です。高速・高耐雑音な完成版ではありません。
- 音響通信は低速です。この版は2 KiBまでに制限しています。
- 送受信上限は2 KiBです。4-FSK・40 ms/シンボルで低速です。高度な前方誤り訂正（FEC）、チャンク再送、周波数追従、クロック回復、適応変調は未実装です。ノイズや端末差によって失敗する可能性があります。
- 受信は録音全体をメモリに保持してから復号するため、長時間録音や大容量ファイルには向きません。
- マイク入力はHTTPSでの公開が必要です（localhostを除く）。
- ファイルはネットワークへ送信しませんが、公開前にコードを確認し、意図しない外部通信がないことを確認してください。
- この試作版は重要なデータの転送に使用しないでください。
