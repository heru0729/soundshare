OTO — 音でファイルを送る

ファイル本体をサーバーに送らず、スピーカーとマイクで端末間転送

試作版・重要：上限8 KiBの音響通信テスト版です。10 ms/シンボルに短縮していますが、雑音や端末差で失敗する場合があります。大容量ファイルや重要なデータには使用しないでください。受信した音声を記録してから復号するため、送信完了後に「録音を停止して復号」を押してください。

16-FSK 周波数帯テスト

オクターブ4〜10を順番に測定します。各帯域で16周波数を1msずつ切り替え、受信側で検出率を集計します。これは転送モードとは独立した試験機能です。

測定前の設定：16-FSK・1ms/記号・送信振幅60%・オクターブ4〜10。音声の実サンプルレートに対しナイキスト周波数を超える音は生成せず、受信側でも検出可能範囲を表示します。1msでは低い周波数の判別が物理的に難しく、結果が低くなる可能性があります。
試験信号の進行未開始
まず受信側でテスト録音を開始し、次に送信側で全帯域テスト音を送信してください。
測定前の設定値：16-FSK · 1ms/記号 · 振幅60% · オクターブ4〜10 · 16音/オクターブ
方式・制約
  • 通常のファイル転送は従来の4-FSK方式です。追加の周波数帯テストは独立した16-FSK試験で、通常転送方式を変更しません。
  • フレームにはファイル名・サイズ・CRC-32を含め、復号後に破損を検査します。
  • 試作版の送受信上限は8 KiBです。通常転送は4-FSK・10 ms/シンボルです。16-FSKテストは1ms/シンボルで帯域ごとの検出率を測りますが、これは1MB転送を保証するものではありません。
  • 高度なFECや自動再送を実装していません。音が欠落すると復号に失敗する可能性があります。
  • 録音データは端末内のメモリで処理し、アプリから外部サーバーへアップロードしません。
  • 受信処理は音の開始マーカーとシンボル時間に依存します。ブラウザー、マイク、スピーカー、音量によって動作結果が異なります。
  • GitHub Pagesにはこの静的サイトのファイルだけを配置します。送受信対象のファイルをリポジトリへ追加しないでください。
